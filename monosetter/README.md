# Monosetter

A zero-build browser tool for wrapping, justifying, centering, and framing monospaced text.

## Use

Open [`index.html`](index.html), choose a preset, enter text, then copy the formatted output. **Use example** places the selected preset’s sample text in the input field.

The app has no network or package dependencies. It is intentionally kept as one HTML file so it can be copied and used on its own.

## Included presets

- Mobile-width text with a four-space left border
- Plain and fully justified 75-column text
- Justified and centered Rocq-style comment boxes
- A compact documentation-comment layout

Long words are split to the selected width, paragraph breaks are retained, and output updates as the input changes.
